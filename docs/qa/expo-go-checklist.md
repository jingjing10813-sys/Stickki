# 스티끼 RN 앱 — Expo Go 테스트 체크리스트

> 준비: PC에서 `cd mobile` → `npx expo start` → iPhone 카메라로 QR 스캔 (같은 와이파이, Expo Go 설치)
> ⚠️ 메일 인증 테스트는 시간당 발송 제한이 있음 — 429 에러가 나면 1시간 뒤 재시도 (SMTP 전환 전까지)

## 1. 로그인 화면
- [ ] 랜딩: 스티끼 워드마크(테이프 로고) + 오른쪽 끝 캐릭터가 보인다
- [ ] 애플/카카오 버튼 탭 → "준비 중" 안내가 뜬다 (정상 — 4주차 연동 예정)
- [ ] "이메일로 로그인하기" → 이메일 로그인 화면 진입
- [ ] 틀린 비밀번호 → "이메일 또는 비밀번호가 올바르지 않아요" 빨간 안내
- [ ] 테스트 계정(test@stickki.com / test1234!) 로그인 성공 → 방으로 이동
- [ ] 앱 완전 종료 후 재실행 → 로그인 유지된 채 방으로 바로 진입

## 2. 회원가입 (새 별칭 이메일: 내주소+아무거나@gmail.com)
- [ ] 이메일 입력 → 오른쪽 "인증요청" 버튼 활성화
- [ ] 메일 도착: 제목 [스티끼] 이메일 인증번호, 노란 포스트잇 디자인
- [ ] 인증번호 입력칸이 아래 나타남 → 코드 입력 → "인증받기" → "이메일 인증 완료 ✓"
- [ ] 틀린 코드 입력 시 → "인증번호가 올바르지 않아요"
- [ ] 비밀번호 불일치 시 빨간 안내, 6자 미만이면 가입 버튼 비활성
- [ ] 약관: 전체 동의 토글 동작, 필수 2개 체크 전엔 가입 버튼 비활성
- [ ] "스티끼 시작하기" → 프로필 그리기 화면으로 자동 이동

## 3. 프로필 그리기
- [ ] 캔버스에 손가락으로 그려진다 (선이 부드러운지, 끊기지 않는지)
- [ ] 펜 3색 전환, "지우기"로 전체 삭제
- [ ] 이름 수정 가능 (기본값 "스티끼")
- [ ] 그림 없으면 "완료" 비활성 / 그리면 활성 → 완료 시 온보딩으로

## 4. 온보딩
- [ ] "새 집 만들기" → 이름 → 가훈 → 방 생성되고 보드 진입
- [ ] (다른 계정으로) "초대코드로 입장" → 마이페이지의 코드 입력 → 입장 성공
- [ ] 틀린 코드 → "존재하지 않는 집입니다"

## 5. 보드
- [ ] 포스트잇들이 흩뿌려진 배치(살짝 회전·어긋남)로 보인다
- [ ] + 버튼 → 할일/쪽지 전환, 색상 선택, 등록 → 보드에 붙는다
- [ ] 쪽지엔 빨간 핀, 할일엔 체크박스가 보인다
- [ ] 체크박스 탭 → 완료(취소선+반투명) ↔ 해제 토글
- [ ] **길게 눌러 드래그** → 카드가 살짝 커지며 따라온다 → 다른 카드 자리에 놓으면 둘이 자리교환
- [ ] 드래그 중 하단에 빨간 휴지통 존 등장 → 끌어다 놓으면 삭제
- [ ] 드래그 중 화면 스크롤이 안 움직인다 (충돌 방지)
- [ ] 가훈 탭 → 인라인 수정 → 엔터로 저장
- [ ] 카드 짧게 탭 → 상세 화면으로

## 6. 실시간 동기화 (기기 2개 또는 웹 로컬과 함께)
- [ ] 한쪽에서 등록 → 다른 쪽에 즉시 나타남
- [ ] 완료 체크/삭제도 실시간 반영
- [ ] 가훈 수정도 상대 화면에 반영

## 7. 상세 / 리스트
- [ ] 상세: 내용 수정 → 저장 → 보드에 반영
- [ ] 담당자 칩(멤버 이름들 + 없음) 선택
- [ ] 마감일 칩: 오늘/내일/일주일/없음
- [ ] 리액션 이모지 탭 → 켜짐(노란 테두리) ↔ 꺼짐, 보드 카드 하단에 이모지 표시
- [ ] 쪽지 상세엔 고정(📌) 토글이 대신 보인다
- [ ] 삭제 버튼 → 확인 → 목록/보드에서 사라짐
- [ ] 리스트(☰): 전체/할일/쪽지/완료 필터 동작, 행 탭 → 상세

## 8. 마이페이지 (👤)
- [ ] 손그림 아바타 + 이름 + 이메일 표시
- [ ] "수정" → 그리기 화면 (이름 미리 채워짐) → 다시 그려 저장 → 반영
- [ ] 초대코드 표시, 멤버 목록 정확
- [ ] 방 나가기 → 확인 → 온보딩으로 (재입장하려면 코드 필요)
- [ ] 로그아웃 → 로그인 화면으로

## 9. 비밀번호 찾기
- [ ] 이메일 로그인 화면 → "비밀번호를 잊으셨나요?"
- [ ] 메일 도착: [스티끼] 비밀번호 재설정 인증번호
- [ ] 코드 입력 → 새 비밀번호 설정 → 새 비밀번호로 로그인 확인

## 10. 탈퇴 (일회용 계정으로만!)
- [ ] 마이페이지 → 계정 탈퇴 → 확인 → 로그인 화면으로
- [ ] 같은 이메일·비밀번호로 재로그인 **안 되면** 성공
- [ ] (다른 멤버 화면에서) 탈퇴자가 멤버 목록에서 사라짐

## 11. 전반 체감 (발견하면 메모)
- [ ] 키보드가 입력칸을 가리지 않는가 (가입/로그인/모달)
- [ ] 노치·홈바에 UI가 겹치지 않는가
- [ ] 화면 전환·버튼 반응이 어색한 곳
- [ ] 글꼴/간격/색이 웹과 크게 다른 곳
